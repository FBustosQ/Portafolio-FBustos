Aplicación web para gestión de proyectos y tareas

Resumen

Aplicación web full-stack desarrollada con Python/Django que permite a múltiples usuarios gestionar sus propios proyectos y tareas en un entorno privado y seguro (arquitectura multi-tenant). Incluye autenticación de usuarios, operaciones CRUD completas e interfaz responsive construida con Bootstrap 5, sobre una base de datos SQLite en entorno Linux.

  • Backend: Python, Django
  • Base de datos: SQLite
  • Frontend: HTML5, CSS3, Bootstrap 5
  • Entorno de desarrollo: Linux

Acciones disponibles

  • Gestión de usuarios
  • Control multiusuario (multi-tenant)
  • Operaciones CRUD completas
  • Interfaz responsive
  • Modo claro / oscuro

Aplicación web para la gestión de itinerarios de transporte

Resumen

Aplicación web para la gestión de itinerarios de transporte, que permite registrar, visualizar y administrar rutas con información detallada de origen, destino, horarios, frecuencia y estado operativo. Incluye una vista de listado general y una vista de detalle por itinerario, con un diseño 100% responsive que transforma las tablas en tarjetas apiladas en dispositivos móviles.

  • Backend: Python, Django
  • Base de datos: SQLite
  • Frontend: HTML5, CSS3, Bootstrap 4
  • Iconografía: Font Awesome 6
  • Entorno de desarrollo: Linux

Acciones disponibles

  • Registro de nuevos itinerarios
  • Listado general con estados dinámicos (Operativo, Con Retraso, Suspendido)
  • Vista de detalle por itinerario con tabla de horarios asociados
  • Operaciones CRUD completas (Crear, Leer, Eliminar)
  • Confirmación previa antes de eliminar un itinerario
  • Mensajes amigables cuando no hay datos registrados
  • Interfaz responsive: tablas → tarjetas en móvil
